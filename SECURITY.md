# Security Policy

## Supported Versions

Only the latest release of `@ipsadt/tg-widgets` receives active security updates and vulnerability patches.

| Version | Supported          |
| :------ | :----------------- |
| `0.1.x` | :white_check_mark: |
| `< 0.1` | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or exploit vector in `@ipsadt/tg-widgets` (such as XSS in template rendering or client script injection), please do **NOT** open a public issue.

Instead, please report it via one of the following private channels:

1. **GitHub Security Advisories**: Submit a report directly at [New Security Advisory](https://github.com/SSA-IPSaDT/tg-widgets/security/advisories/new).
2. **Direct Email**: Send details and reproduction steps to [naylour@tuta.io](mailto:naylour@tuta.io).

### Response SLA:
- We acknowledge valid vulnerability reports within **48 hours**.
- We aim to provide a security patch or mitigation within **7 days** of confirmation.
- Public credit will be attributed in release notes once the patch is published.
